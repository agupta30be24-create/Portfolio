# Portfolio website recreation

This project recreates the portfolio layout shown in the supplied screenshots using plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Edit the content in `index.html` to change your personal information, projects, links, or experience.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, typography, responsive design, and animations
- `script.js` — smooth section navigation and reveal-on-scroll effects

Note: This is a close visual recreation based on the provided screenshots. Exact original source code, assets, and hidden interactions from the hosted site were not available. Google Fonts are loaded online; fallback fonts are included.
